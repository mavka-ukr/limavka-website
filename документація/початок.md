# ЛіМавка

ЛіМавка це прошивка на основі [KeiraOS](https://github.com/lilka-dev/keira) для української саморобної консолі [Лілка](https://lilka.dev) з підтримкою української мови програмування [Мавки](https://мавка.укр).

ЛіМавка надає можливість писати програми для Лілки повністю українською мовою!
