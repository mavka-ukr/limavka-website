# ЛіМавка

<a href="./ресурси/тема/photo.jpg"><img src="./ресурси/тема/photo_comressed.jpg"></a>

ЛіМавка це прошивка на основі [KeiraOS](https://github.com/lilka-dev/keira) з підтримкою української мови програмування [Мавка](https://мавка.укр) для української саморобної консолі [Лілка](https://lilka.dev).

ЛіМавка надає можливість писати програми для Лілки повністю українською мовою!
